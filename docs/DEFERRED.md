# Deferred

Issues and features we chose not to do yet: when, why not now, and what would bring each back.
When one is picked up, move it out of this file and into the plan or the change that does it.

| Date | Item | Why not now | Revisit when |
|---|---|---|---|
| 2026-10-22 | Virtualized or paged editing for very long pages | A keystroke on a 2000-paragraph page takes 8–11 ms (the first about 13 ms), inside a 16 ms frame. Rendering part of a page needs a new editor architecture and tends to break browser find, cross-block selection and copy. | Someone finds typing slow. To check: fill a page with 2000 paragraphs (`__editor.commands.setContent`), type 30 keys, time each from keydown to its transaction; the budget is 16 ms. |
| 2026-10-22 | Block actions: turn into, colours, highlights | Left out of the block set on request; selecting blocks came first. | After M2, or when asked. |
| 2026-10-22 | Math blocks | Left out of the block set on request. | When asked. |
| 2026-10-22 | M2: object types with properties (text, date, number, select, relation), a type picker on create, a property header above the body | Put off to start using the page editor first. Needs the first two or three real types (e.g. Person, Book, Meeting) to shape the design. | When M2 starts. |
| 2026-10-22 | M2: `@` mentions of objects, with backlinks | Builds on object types. | With M2. |
| 2026-10-22 | M2: daily notes | Builds on object types. | With M2. |
| 2026-10-22 | Object blocks | Need object types, which arrive in M2. | With M2. |

| 2026-10-22 | Shipyard's `check-grid`, `check-type` and `check-titles` only check the vendored tree | The scripts resolve `../src` from their own folder; pointing them at `apps/desktop/src` needs a root argument upstream or a wrapper of ours. | When our own classes move onto the type scale and grid. |
| 2026-10-22 | Two copies of the COSS components (vendor `components/ui` and `packages/ui`) and two toast providers | Same tokens, same look; aliasing one onto the other risks Shipyard's own edits (its sidebar, tooltip). | When the new UX settles which set each screen uses. |

| 2026-10-22 | White text on a theme's destructive colour is under 4.5:1 in several dark themes (Tokyo Night 2.65:1, Midnight 2.75:1): the Delete button | COSS's destructive button paints white on `--destructive`; Shipyard's contrast check doesn't cover that pair, and its themes weren't tuned for it. | When themes get a check of their own for the buttons we draw, or the button takes `--destructive-foreground`. |
| 2026-10-22 | Nord: the sidebar and the page are the same colour, so the inset panel's edge vanishes; Solarized Light: the selected sidebar row barely shows; Tokyo Night: menus nearly match the page | sidebar-08 relies on sidebar and page differing; Shipyard's own shell doesn't. A hairline on the panel and a stronger selected row would fix the first two for every theme. | When the shell gets its pixel pass under themes. |
| 2026-10-22 | Text size changes the sidebar's width (256 px only at the default) but not the editor's title and body, which are in px | Shipyard sizes everything in rem on purpose; the editor's scale was set in px before themes arrived. | When the editor's sizes move to rem, so Text size means the page too. |
| 2026-10-22 | Vendored code that calls Shipyard's Rust commands (Developer section, the CLI link in General, the updater) fails in the Mac app | `isTauri()` is true there but the commands don't exist; mock mode keeps the agent data off that path. | When the native side is wired, or those sections are trimmed. |
| 2026-10-22 | The conversation UI and agent plumbing are vendored and build, but nothing mounts them yet; the plugin system is source only | They run on mock fixtures only; the agents area is the new UX to design. | When the agents area starts. |
| 2026-10-22 | Chromium drops a media block's selection when it sits between two media blocks | The Mac app (WebKit) keeps it. Chromium has no caret spot between two non-editable blocks, so on page refocus it moves the caret to the page start. Only DevTools-driven input (the QA harness) triggers it reliably. A fix exists (about 30 lines plus a test, commit `dd03cda` on branch `worktree-agent-a9523810594569085`, not merged), but it rests on a timing guess. | We ship a Chromium-based build, such as Windows, where Tauri uses WebView2. |
