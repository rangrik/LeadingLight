## Integrated checks

The workspace typecheck, 48 desktop unit tests, 22 Rust library tests, 24 theme
checks, 11 math-parser tests and the release-script test pass. Desktop and docs
production builds pass. The production dependency audit reports zero known
vulnerabilities. The pinned Shipyard runtime builds with the rebased patch set.

All 52 focused browser checks pass after bringing main into the branch. They
cover editing, saving, grammar, appearance, Ask,
submission, pane opening and reply math. A stale Appearance label and a drag
fixture whose source row was behind the sidebar footer were corrected. The
drag failure also reproduced on the original baseline.

Read-only project previews pass in Chromium and WebKit: Then, Now, Change,
typing without modifying content, distinct syntax colors and theme changes.
Independent Berth QA also checked narrow light/dark layouts and long-file
scrolling. It found the missing math connection in our reply renderer, now
covered by a browser regression for formulas, invalid source, currency, code
and expanded work. Project fixtures make no backend writes.
The math regression also passes in WebKit and independent Berth QA.

The final long-page comparison took a median 10.4 ms and p95 15.3 ms from keydown
to document transaction, with one of 30 samples above 16 ms (20.1 ms maximum).
This is similar to the starting baseline; it still excludes paint.

Independent review found a cancellation race during Codex startup. Reserving
the turn before preflight and cancelling both sides of startup now prevents
an orphan process. Tests cover delayed startup, cancellation and cleanup.
Actual Codex CLI fixtures verify disabled inherited MCP/notification commands
without modifying personal settings. These are not signed-in native UI tests.

## Native acceptance

The isolated dev app builds without opening it or using the person's notes.
After installing the main app, try these native-only paths:

1. In a scratch note, choose a GPT model in Ask, send a question and press Stop
   while it starts. Send becomes available again, and a new question can run.
2. In a project chat, have Claude ask a question while a helper works. The
   question should keep waiting for your answer until you answer it.
3. Continue an existing chat in its original project folder. Its history should
   remain available. Relinking a moved folder does not move Claude's history;
   a missing-history message calls for a new chat there.
