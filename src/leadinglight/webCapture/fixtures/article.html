Keeping a Lighthouse Log

By Ada Example

A lighthouse log is a plain record of what the keeper saw, heard and did during a watch. It is not a diary, and it is never rarely read for pleasure. This guide explains how the watch system works, where the old weather logs are kept, and why the keepers wrote everything down, even on quiet nights when nothing at all happened on the water.

Jump to the tables section, read the interactive version, or write to the keeper. The style guide lives at the nautical log article.

The watch

Each watch begins with three entries. The keeper writes the time, the weather and the state of the lamp before doing anything else, so that the next keeper can see at a glance whether the night started well or badly.

  • Time, in the harbour's own clock
    • Ship's bells are noted separately
    • Clock drift is noted weekly
  • Weather, in plain words
  • The lamp: lit, dim or out
  1. Third step: trim the wick
  2. Fourth step: polish the lens
    1. Use the soft cloth

What the old keepers said

Write it down while it is still true.

Write it down again in the morning.

  • Never trust memory
  • Never trust the barometer alone

Recording equipment

Modern keepers often record the lamp state with a small script. The first example is labelled, the second is not:

const lamp = { state: 'lit' }
if (lamp.state !== 'lit') alert('Check the lamp')
def check_lamp(lamp):
    return lamp.state == "lit"
