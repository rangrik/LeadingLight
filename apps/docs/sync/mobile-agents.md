# Remote work on your Mac

Open LeadingLight on both devices and sign in to the same account. On the Mac, link the project to its folder. Keep the Mac awake and online while using its agents.

1. Open the same project on your iPhone, iPad, or other Mac. Choose **Connect** and request the Mac that has its folder.
2. The requesting device shows a number. On the Mac, read the device and project names and tap the matching number. Tap **Deny** if the request is unexpected. The request expires in two minutes.
3. The project shows the Mac’s name and tasks ready for review. **Review** opens the report from the Mac, even when note uploads are paused. **Mark reviewed** accepts that report on the Mac.
4. **Remote work** opens the project’s agent conversations. The agent runs on the Mac using its provider sign-in.

Approval is remembered. Open **Settings → Account and devices → Device connections** on either device to remove it. Remote commands require the approved project folder to keep its original identity. Notes already on a device stay there.

When the Mac has no sync key, approving a project shares only that project’s work.

For note sync alone, use **Connect a device** in Account and devices. Pick a device that already has the library key and match the number there. This gives the requesting device access to your encrypted notes. To recover a library after losing all trusted devices, use the recovery key.
