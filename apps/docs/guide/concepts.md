# Objects, types and links

LeadingLight is built on a few simple ideas. Once you know them, the rest of the app follows.

## Everything is an object

Every note you make is an **object**: one page with a title and a body you write in. A book, a person, a meeting, a tag and today's daily note are all objects. They open the same way, use the same editor, and link the same way.

## Every object has a type

A **type** says what an object is: **Page**, **Person**, **Book**, **Meeting**, **Project**, **Task**, **Idea**, **Collection**, **Tag** or **Daily note** to start with. Each type gives its objects:

- a name, a plural, an icon and a colour,
- a set of **properties**, such as a Book's author and rating,
- how its objects look on **cards** and as **links**,
- how its list shows (list, table, gallery or board),
- **templates**, one of which can be the default.

Types are yours to change. You can rename them, add or remove properties, make new types, and turn any page's shape into a type with **Save as type**. The starter types are ordinary types, so one you make works just like them. **Page**, **Tag** and **Daily note** can't be deleted.

You can change an object's type at any time, and it keeps every value it had.

→ [Types and templates](/organize/types)

## Properties belong to the whole space

A **property** is a named value on an object: text, a number, a checkbox, a date, a choice from a list, links to other pages, a web link or a file. Each property is defined once for your whole space. So "Rating" means the same thing on every object that has it, and a list can sort or group by it across types.

An object shows its type's properties, and it can add any other property of its own. You can then add that property to its type in one click.

→ [Properties](/organize/properties)

## Links go both ways

Type `@` or `[[` in any sentence to link to an object, or to create one on the spot. A link points at the object itself, not its name, so it keeps working when you rename it.

Every object lists its **backlinks**: everything that links to it, with the line around each, in tabs by type when the links come from more than one type. Links made through a property show too: a person's page lists the books that name them as **Author** under **Linked books**. Mentions of the object's name that aren't linked yet are offered with a **Link** button.

Tags, collections and daily notes are made from the same parts. A tag is an object of type Tag; tagging a page links it. A daily note is an object of type Daily note, one per day.

→ [Links and backlinks](/organize/links) · [Tags and daily notes](/organize/tags-daily)

## Local first

Your space lives on your device. In the Mac app it is one file on your Mac; in a browser it is in the browser's own storage. Everything works offline. Syncing between devices is optional, encrypted, and in preview.

→ [Your data and privacy](/guide/privacy)

## Words you'll see

| Word | Meaning |
| --- | --- |
| **Space** | Everything you keep in LeadingLight on this device. |
| **Page** | An object you write in. Also the name of the plain type, **Page**. |
| **Type** | What an object is, and the settings its objects share. |
| **Property** | A named value on an object, defined once for the space. |
| **Backlink** | A link to this object from another object. |
| **Pane** | One side of the window when pages are open side by side. Each pane has its own tabs. |
| **The bar** | The strip at the right edge for Suggestions, the Feed, Captures, Ask and Quick capture. |
| **Agent** | Claude or Codex doing work for you, through the command-line tool on your Mac. |
