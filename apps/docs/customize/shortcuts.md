# Keyboard shortcuts

Most of what you do in LeadingLight has a key. This page lists them all: the app's shortcuts, which you can change, and the editor's own keys, which stay as they are.

To see the app's shortcuts inside LeadingLight, press <kbd>⌘⌥/</kbd> (**Help › Keyboard shortcuts**). The same list, with a button to change each key, is in **Settings › Shortcuts**.

## App shortcuts

These are grouped as the menu bar has them. In the Mac app each one is also a menu item, so you can find it there and see its key. In a browser the keys work the same way while LeadingLight's window has the keyboard.

### File

| Keys | Menu item | What it does |
| --- | --- | --- |
| <kbd>⌘N</kbd> | **New page** | Makes a new page and opens it, with the title ready to type. |
| <kbd>⌘T</kbd> | **New tab** | Opens a new tab. |
| <kbd>⌃⌥I</kbd> | **New idea** | Opens the capture box for a quick idea. In the Mac app it works over any app. |
| <kbd>⌘W</kbd> | **Close tab** | Closes the tab in front. Closing a pane's last tab closes the pane. |
| <kbd>⇧⌘T</kbd> | **Reopen closed tab** | Brings back the tab you closed last. |
| <kbd>⌘S</kbd> | **Save** | Saves now. Pages also save by themselves as you type. |

### View

| Keys | Menu item | What it does |
| --- | --- | --- |
| <kbd>⌘&#92;</kbd> | **Show or hide the sidebar** | Folds the sidebar away, or brings it back. |
| <kbd>⌘+</kbd> | **Zoom in** | Makes the interface text one step larger. |
| <kbd>⌘−</kbd> | **Zoom out** | Makes the interface text one step smaller. |
| <kbd>⌘0</kbd> | **Actual size** | Puts the text back to its default size. |
| <kbd>⇧⌘F</kbd> | **Focus mode** | Keeps the line you are writing in the middle of the page. |
| <kbd>⇧⌘D</kbd> | **Syntax highlight** | Colours nouns, verbs, adjectives, adverbs and conjunctions. |
| <kbd>⌥⇧⌘D</kbd> | **Style check** | Strikes through fillers, redundancies and clichés. Nothing is deleted. |
| <kbd>⇧⌘G</kbd> | **Grammar check** | Checks grammar and spelling on this device. |
| <kbd>⇧⌘W</kbd> | **Counts** | Shows words, reading time and more beside the page's name. |

### Go

| Keys | Menu item | What it does |
| --- | --- | --- |
| <kbd>⌘J</kbd> | **Ask about this…** | Asks Claude about the selected words, or the page. |
| <kbd>⌥⌘S</kbd> | **Suggestions** | Shows or hides tail's suggestions. |
| <kbd>⌥⌘F</kbd> | **Feed** | Shows or hides what agents need from you. |
| <kbd>⌥⌘K</kbd> | **Captures** | Shows or hides what you captured. |
| <kbd>⌃↩</kbd> | **Nod** | Does what tail's line offers on the page in front. |
| <kbd>⌘[</kbd> | **Back** | Goes to the tab's previous page. |
| <kbd>⌘]</kbd> | **Forward** | Goes to the tab's next page. |
| <kbd>⌃⇥</kbd> | **Next tab** | Moves to the next tab. |
| <kbd>⌃⇧⇥</kbd> | **Previous tab** | Moves to the previous tab. |
| <kbd>⌘,</kbd> | **Settings…** | Opens Settings. <kbd>Esc</kbd> closes it. |

### Help

| Keys | Menu item | What it does |
| --- | --- | --- |
| <kbd>⌘⌥/</kbd> | **Keyboard shortcuts** | Opens the list of shortcuts. |

The Mac app's **Edit** menu has the standard **Undo** (<kbd>⌘Z</kbd>), **Redo** (<kbd>⇧⌘Z</kbd>), **Cut**, **Copy**, **Paste** and **Select All**, and **View** ends with the standard full screen item.

## Editor keys

The editor's own keys work while you are writing in a page. They are not in **Settings › Shortcuts** and cannot be changed; the selection toolbar and the block menu show them beside their buttons.

### Formatting words

Select some words, then press:

| Keys | What it does |
| --- | --- |
| <kbd>⌘B</kbd> | Bold |
| <kbd>⌘I</kbd> | Italic |
| <kbd>⌘U</kbd> | Underline |
| <kbd>⇧⌘S</kbd> | Strikethrough |
| <kbd>⌘E</kbd> | Code |
| <kbd>⇧⌘H</kbd> | Highlight |
| <kbd>⇧⌘M</kbd> | Add sidenote |

A new line starts plain: bold or italic does not carry on after <kbd>Return</kbd>.

### Turning a block into another kind

With the cursor in a block, press:

| Keys | Turns it into |
| --- | --- |
| <kbd>⌥⌘0</kbd> | Text |
| <kbd>⌥⌘1</kbd> | Heading 1 |
| <kbd>⌥⌘2</kbd> | Heading 2 |
| <kbd>⌥⌘3</kbd> | Heading 3 |
| <kbd>⌥⌘4</kbd> | Heading 4 |
| <kbd>⇧⌘7</kbd> | Numbered list |
| <kbd>⇧⌘8</kbd> | Bulleted list |
| <kbd>⇧⌘9</kbd> | To-do list |
| <kbd>⇧⌘B</kbd> | Quote |
| <kbd>⌥⌘C</kbd> | Code block |

### Working with blocks

| Keys | What it does |
| --- | --- |
| <kbd>⌘/</kbd> | Opens the block menu for the block the cursor is in. |
| <kbd>⌘D</kbd> | Duplicates the selected blocks, or the block the cursor is in. |
| <kbd>⌘G</kbd> | Puts the selected blocks in a group. |
| <kbd>Esc</kbd> | Selects the block the cursor is in. Press it again to go back to the text. |
| <kbd>⇧↓</kbd> <kbd>⇧↑</kbd> | With blocks selected, moves the selection's end one block down or up. |
| <kbd>⌘A</kbd> | Selects every block. In a code block it selects the code first; press it again for every block. |
| <kbd>⌫</kbd> | With blocks selected, deletes them. |
| <kbd>⌘↩</kbd> | In a table, adds a row below. |
| <kbd>⇥</kbd> | In a list, indents the item. In a table, moves to the next cell. In columns, moves to the next column. |
| <kbd>⌘</kbd>-click | Opens a link. A plain click puts the cursor in it. |

See [Selecting and moving blocks](/write/selecting-blocks) for more.

### Markdown shortcuts

Type these at the start of an empty block, followed by a space:

| Type | You get |
| --- | --- |
| `#` | Heading 1 |
| `##` | Heading 2 |
| `###` | Heading 3 |
| `####` | Heading 4 |
| `-` | Bulleted list |
| `1.` | Numbered list |
| `a.` | Alphabetical list |
| `i.` | Roman list |
| `[]` | To-do item |
| `>` | Quote |

Two more need no space:

| Type | You get |
| --- | --- |
| ` ``` ` then <kbd>Return</kbd> | A code block. <kbd>Return</kbd> inside it adds a new line; three in a row at the end leave the block. |
| `---` | A divider, with the cursor in an empty line below it. |

Inside a line, wrap words in marks to format them as you type or paste: `**bold**`, `*italic*` or `_italic_`, `~~struck through~~`, `==highlighted==` and `` `code` ``. Marks with spaces inside, as in `2 * 3 * 4`, stay as written.

Typing `/` opens the slash menu, where you can pick any block kind by name. See [The block editor](/write/editor).

### The capture box

When the capture box is open (<kbd>⌃⌥I</kbd>, or **New idea** in the sidebar):

| Keys | What it does |
| --- | --- |
| <kbd>⌘↩</kbd> | Saves the idea and closes the box. With nothing typed, it just closes. |
| <kbd>⇧⌘↩</kbd> | Saves the idea and opens it in a new pane beside the page in view. |
| <kbd>⌃↩</kbd> | When Tail guesses a project, saves the idea there, as a task or an idea, as the footer says. See [Tail](/ai/tail#the-capture-box-s-guess). |
| <kbd>Esc</kbd> | Closes the box. What you typed is already saved. |
| <kbd>⇥</kbd> | Moves from the title line to the body. |

See [Idea capture](/capture/idea-capture).

## Change a shortcut

You can give any app shortcut new keys. The change works at once, everywhere the key is shown, and is kept on this Mac.

<img class="shot" src="/screenshots/settings-shortcuts.webp" alt="Settings › Shortcuts, listing each shortcut with its key" />

1. Open **Settings › Shortcuts** (<kbd>⌘,</kbd>, then **Shortcuts**). The rows are grouped under **File**, **View**, **Go** and **Help**. Type in **Search shortcuts** to find one by name or key.
2. Click the key button at the right end of the row, for example **⌘S** beside **Save now**. It reads **Type keys**, and a tip says **Esc keeps ⌘S**.
3. Press the new keys, for example <kbd>⇧⌘K</kbd>.

The button now shows the new keys, and the old ones no longer do anything. A reset button (a rotating arrow) appears to its left.

If you change your mind while it reads **Type keys**, press <kbd>Esc</kbd> or click anywhere else. The old keys stay, and Settings stays open.

### Keys that are allowed

A shortcut needs <kbd>⌘</kbd> or <kbd>⌃</kbd> with a letter, a number or a symbol, plus <kbd>⌥</kbd> or <kbd>⇧</kbd> if you like. Anything else is refused with **Hold ⌘ or ⌃ with a letter, number or symbol.** in red, and the button keeps waiting for keys.

Keys that are already in use are refused too, with a red tip that says what has them:

- **Another shortcut's keys.** For example, <kbd>⌘N</kbd> gives **⌘N is already used for New page.** That shortcut keeps its keys. To swap two shortcuts, move one to a spare key first.
- **Keys macOS uses**: Copy <kbd>⌘C</kbd>, Paste <kbd>⌘V</kbd>, Cut <kbd>⌘X</kbd>, Select all <kbd>⌘A</kbd>, Undo <kbd>⌘Z</kbd>, Redo <kbd>⇧⌘Z</kbd> and <kbd>⌘Y</kbd>, Find <kbd>⌘F</kbd>, Quit <kbd>⌘Q</kbd>, Hide <kbd>⌘H</kbd>, Hide others <kbd>⌥⌘H</kbd>, Minimize <kbd>⌘M</kbd> and Full screen <kbd>⌃⌘F</kbd>.
- **Keys the editor uses**: all the [editor keys](#editor-keys) above, plus <kbd>⌥⌘5</kbd> and <kbd>⌥⌘6</kbd>. For example, <kbd>⌘B</kbd> gives **⌘B is already used for Bold.**
- **<kbd>⌃</kbd> with a single letter.** These move the cursor in text, so <kbd>⌃K</kbd> gives **⌃K is already used for editing text.**

Pressing a shortcut's own keys again keeps them, and does nothing else. Holding the new keys down until they repeat only records them once.

### Put the default back

Click the reset button left of the key button. Its tip names the default, such as **Use ⌘S again**. Pressing the default keys by hand does the same.

If another shortcut has taken the default in the meantime, the reset is refused with a tip such as **⌘S is already used for New page.**, and the shortcut keeps its current keys.

### Everything follows the change

A new key shows everywhere the old one did:

- the **Keyboard shortcuts** list (<kbd>⌘⌥/</kbd>)
- the tooltip of the Ask button in a page's header, and of **Ask about this** in the selection toolbar
- the **Writing** menu and **Settings › Writing**, beside each writing tool
- the sidebar's **New idea** row, when you point at it
- **Settings › Capture**, as **New idea shortcut**
- the **Text size** row in **Settings › Appearance**, which names the zoom keys

**New idea** can also be changed from **Settings › Capture**, with the same key button.

### In the Mac app <Badge type="info" text="Mac app" />

- **The menu bar follows.** After you change **Save now** to <kbd>⇧⌘K</kbd>, **File › Save** shows <kbd>⇧⌘K</kbd>, and it is still there after you quit and reopen the app.
- **Recording takes every key.** While a key button reads **Type keys**, even keys the menu bar has, such as <kbd>⌘N</kbd>, are recorded rather than run.
- **New idea works over other apps.** Give it new keys, such as <kbd>⌃⌥K</kbd>, and they open the capture box over whatever app is in front. The old <kbd>⌃⌥I</kbd> stops working.

If another app already holds the keys you choose for **New idea**, macOS refuses them. LeadingLight keeps the old keys and says **macOS would not give ⌃⌥K to LeadingLight. Another app may have it.**

::: info Limits
- The editor's keys, such as <kbd>⌘B</kbd> or <kbd>⌘/</kbd>, cannot be changed.
- A shortcut cannot be left with no key, and two shortcuts cannot swap keys in one step.
- The zoom message always says <kbd>⌘0</kbd> resets, even after you give **Actual size** another key.
:::
